## Recommended Use

### 1. Start with the synthesis matrix

Use `comparative_synthesis_matrix_stage_19.md` first when the question is strategic or architectural.

### 2. Move to the regional matrix

Use `comparative_matrix_by_region.md` when the question is:

- whether a pattern is region-native;
- whether a concept is production-led or delivery-led;
- whether Middle East, CIS, China, USA, or EU should be the stronger reference point.

### 3. Use academic and enterprise matrices together

These two matrices should be paired when tracing how a concept moves from teaching into operating practice.

### 4. Use software matrices only after the conceptual layer is clear

Software matrices are strongest when the question is:

- how the concept appears as data and workflow;
- which family the product supports best;
- where documentation confidence is strong or weak.

### 5. Use the reporting-practice matrix when the question is about dashboards and packs

Use `comparative_matrix_by_reporting_practice.md` when the question is:

- which reporting container should sit above the schedule system;
- how executive dashboards differ from monthly controls packs;
- which KPI families recur across regions;
- where pilot dashboard design should borrow from enterprise practice and where it should stop.
