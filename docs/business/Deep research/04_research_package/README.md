# Research Package: Stage 20 Assembly

This folder assembles the current research corpus into a compact working package for reading, comparison, and later target-model drafting.

The package does not replace the authoritative research files in:

- `02_registries/`
- `03_reports/`

It organizes them.

## Package Contents

- `01_narrative_report.md`: assembled high-level narrative across the full corpus.
- `02_comparative_matrix_pack.md`: guide to all comparison matrices and how to use them.
- `03_catalog_pack.md`: guide to the entity, property, coding, process, and emergent catalogs.
- `04_software_report_pack.md`: guide to global and Asia software findings.
- `05_source_register_pack.md`: guide to the source base and source hierarchy.
- `06_research_package_manifest.md`: consolidated manifest of the assembled package.

## Recommended Reading Order

1. `01_narrative_report.md`
2. `02_comparative_matrix_pack.md`
3. `03_catalog_pack.md`
4. `04_software_report_pack.md`
5. `05_source_register_pack.md`
6. `06_research_package_manifest.md`

## Working Rule

This package remains a research-stage assembly. It does not narrow findings to the future pilot model and should not be treated as the final business model.
