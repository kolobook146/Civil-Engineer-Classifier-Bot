# Source Register Pack

## Purpose

This document explains how to use the source base assembled in the research corpus.

## Primary Authoritative File

- `../02_registries/source_registry.md`

## Source Hierarchy

### Level A

Primary and practice-significant sources:

- standards
- regulations and official methods
- university and official course materials
- official software documentation
- owner and contractor requirements
- enterprise and institutional practice sources

### Level B

Strong secondary sources:

- textbooks
- academic tutorials
- secondary access to important standards where public primary copies are difficult to access

### Level C

Auxiliary sources:

- not a major part of the current assembled corpus

## Main Source Clusters

### Institutes and universal core

- GAO

### Regional core

- CIS / Russia norms and university sources
- EU institutional and megaproject sources
- U.S. owner and assurance sources
- China standards and digital-governance sources
- Middle East owner, authority, PMIS, and megaproject sources

### Software core

## Reading Rule

- Prefer Level A when making structural conclusions.
- Use Level B to enrich interpretation, not to overturn stronger Level A evidence.
- When public access is uneven, distinguish `source authority` from `access-mode confidence`.

## Package Use

The source register pack is the traceability layer of the Stage 20 package. All higher-level package documents depend on it.
